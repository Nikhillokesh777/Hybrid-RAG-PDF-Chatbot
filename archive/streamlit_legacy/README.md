# Legacy Streamlit Prototype

This directory contains the original Streamlit-based prototype for the Hybrid PDF RAG Chatbot:

- **`app.py`**: The Streamlit user interface script.
- **`styles.py`**: Streamlit custom CSS definitions.
- **`ui_components.py`**: Streamlit sidebar, message rendering, and metric widgets.

### Running Legacy Version (Optional)
If you ever need to inspect or run this legacy version:
```bash
streamlit run archive/streamlit_legacy/app.py
```
